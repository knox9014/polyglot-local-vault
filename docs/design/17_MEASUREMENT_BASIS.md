# 17. Measurement Basis

v0.2의 모든 수치는 실제 데이터 측정값이다. 이 문서는 그 출처와 조건, 그리고 한계를 기록한다.

**수치를 인용할 때는 이 문서의 조건을 함께 인용해야 한다.** 조건 없는 수치는 검증 불가능한 목표가 된다.

## 측정 환경

| | |
|---|---|
| CPU | Intel Xeon @ 2.10GHz, **2 코어** |
| 검색 구현 | Rust, `opt-level=3`, `lto=true`, `codegen-units=1` |
| 파서 | tree-sitter 0.26 (python / go / typescript / rust) |
| 대조군 | CPython 3.11 `ast` |
| 통계 | 워밍업 후 15~60회 반복, p50 / p95 / p99 |

> **2코어는 실사용 개발 머신(8~16코어)보다 훨씬 약하다.** 절대값이 아니라 한계점의 위치와 상대 기여도로 읽어야 한다. 병렬 효율 0.86이 실측되었으므로 코어 수에 따른 외삽이 가능하다.

## 측정으로 기각된 설계안

구현하지 않기로 한 것들이며, 각각의 기각 근거를 남긴다.

| 안 | 기각 근거 |
|---|---|
| 문자 집합 비트마스크 프리필터 | 짧고 흔한 쿼리에서 통과율 97%. 무효 |
| Incremental 후보 축소 (성능 목적) | 후보가 19만으로 유지되어 전체 스캔과 동일 비용 |

## 측정의 한계

수치를 신뢰할 수 있는 범위를 명확히 하기 위해 기록한다.

1. **2코어 Xeon 2.1GHz.** 실사용 머신보다 약하다. 병렬 효율 0.86으로 외삽 가능하나 절대값은 보수적으로 읽어야 한다.
2. **검색 코퍼스가 극단 케이스다.** 232K는 대형 저장소 5개를 합친 규모다. 실제 vault 하나는 1K~50K가 일반적이며 그 구간은 전부 여유 있게 통과한다.
3. **제안 엔진의 정밀도를 측정하지 못했다.** 자동 지표 두 개가 실패했고 세 번째도 실존 심볼을 버린다. **정밀도 수치를 제시하지 않는 것이 정직한 상태다.** 승인율도 마찬가지로 미측정이다.
4. **call edge의 UNIQUE 판정은 이름 단위다.** import 정보를 결합하면 `bare` 유일률은 73.0%보다 올라간다. 이 값은 **하한**이다.
5. **인덱스 크기의 TF/위치 포함 수치는 추정이다.** doc ID만 저장한 5.5%는 실측이지만 7.3% / 21.8%는 계산값이다.
6. **TypeScript 표본이 작다.** 2 저장소 2,314 심볼. date-fns는 과거에 `.js` 였고 prettier는 `.mjs` 비중이 커서 `.ts` 심볼이 적었다. 다른 언어보다 신뢰도가 낮다.
7. **모든 측정에서 vendored 코드를 제외했다.** 실제 사용자 vault도 그럴 것이므로 타당하지만 `.gitignore` 기반 자동 제외가 전제된다.
8. **GONE(심볼 소멸) 판정이 유사도 오라클에 의존한다.** 완전히 재작성되었지만 개념적으로 같은 함수는 GONE으로 분류되어 분모에서 빠진다. 복구율을 과대평가하는 방향이다.
9. **Python / Go / TypeScript / Rust만 측정했다.** Java, C++, JS는 미측정이다.
10. **모든 측정이 "어떻게 만들 것인가"에 대한 것이다.** "만들 가치가 있는가"는 측정하지 않았고 측정할 수 없다. 제품 리스크는 그대로 남아 있다.

## 재현

측정 코드 일체는 별도 패키지 `vault-bench` 로 보관한다.

```text
search/    Rust — 퍼지 검색 벤치마크 3종
resolve/   Python — 파일 링크 복구율 2종
symbol/    Python — 심볼 복구율 2종, 파서 복원력 1종
m1_m6/     Python + Rust — 언어별 복구율, 제안 엔진, call edge,
                            정합성 스캔, 파라미터 스윕, 인덱스 규모
raw_output/ 원본 stdout + 통합 데이터셋 (measurements.json)
```

코퍼스는 공개 저장소이므로 누구든 재현할 수 있다. 다만 HEAD가 움직이므로 수치는 정확히 재현되지 않는다. 재현 시에는 측정일(2026-08-16) 기준 커밋으로 고정하는 것을 권한다.
